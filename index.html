About Me

Offensive security practitioner focused on web application pentesting, API security and VAPT — pursuing an M.Sc. in Cyber Security (2025–2027) at Dr. Babasaheb Ambedkar Open University, after a BCA from Gujarat University.

Before security I spent a year as a MERN Stack Intern at Infolabz, Ahmedabad, building full-stack apps. I read code like a builder and test like an attacker — auth flows, access control and API logic are where I find the bugs scanners miss.

Today I hunt on private bug bounty programs, report vulnerabilities to open-source projects via GitHub Security Advisories, and prepare for BSCP alongside the WEB-RTA and HTB CWES tracks.
